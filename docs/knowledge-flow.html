知識迴圈 — v1 提案（review 完非同步跑，不擋使用者）

v1 範圍：knowledge repo 就放本地 —— 照 rules repo 的成功模式： 伺服器上一個目錄 + git init（子樹 SHA 當版本錨），env 指 KNOWLEDGE_ROOT， 免遠端、免新服務。哪天要全組共筆，加 remote push 上去即可，程式零改動。
K1訊號過濾 — 這條 PR 值得寫史嗎code

純 code 閘門：描述長度、有無 work item、討論深度、是否碰核心目錄。 八成的 bump-version PR 在這裡出局——防「write-only 墓園」的第一道閘。

吃的全是現成產物：PR 摘要、各面向 assessment、graph 受影響實體、規則稽核。 產出 { summary, decisions[], invariants[], affected_entities, evidence links }—— 每條知識必附 PR / commit / 行號連結，條目是「證據之上的視圖」，不是自由散文。
